# E-commerce Customer Behavior & Funnel Analysis

Pet-project по анализу поведения пользователей интернет-магазина
на основе Retailrocket recommender system dataset.

## Цели проекта

- исследовать поведение пользователей;
- построить воронку View → Add to cart → Transaction;
- определить товары и категории с высокой конверсией;
- провести пользовательскую сегментацию и когортный анализ;
- подготовить SQL-запросы и dashboard в Power BI.

## Технологии

Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, PostgreSQL,
Power BI, Jupyter Notebook.
